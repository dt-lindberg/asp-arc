## Clingo Reference

A condensed reference for writing valid Clingo programs:

### Rules
- **Fact**: `p(1).`
- **Rule**: `head :- body1, body2, ..., bodyN.`
- **Integrity constraint**: `:- body.`
- **Disjunction in head**: `a ; b :- body.` (avoid unless needed).

### Negation
- `not p(X)` — default negation. `X` must be bound by a positive literal elsewhere in body.
- `-p(X)` — classical (strong) negation.

### Choice Rules
- `{ p(X) : dom(X) }` — choose any subset.
- `1 { color(N,C) : color(C) } 1 :- node(N).` — exactly one.

### Aggregates
- `#count { X : p(X) }`
- `#sum { W,Id : edge(Id,W) }`
- Use in body: `N = #count { X : p(X) }`, `:- #count { X : p(X) } > 3.`

### Arithmetic & Comparison
- Operators: `+ - * / \` (modulo is `\`)
- Comparisons: `=`, `!=`, `<`, `<=`, `>`, `>=`
- Variables in arithmetic must be bound by a positive literal first.

### SAFENESS (CRITICAL)
Every variable must appear in at least one **positive, non-arithmetic** body literal.

### COMMON PITFALLS
- Variables only inside `not`, comparisons, or arithmetic -> UNSAFE.
- Integer division is `/`; modulo is `\` (single backslash).
- Use `<=`, NOT `=<` (that is Prolog syntax).
- Aggregate results cannot be used inline: `W = #max{...} + 1` is INVALID.
  Assign first: `W1 = #max{...}, W = W1 + 1.`
- Disjunction in bodies: use separate rules, one per disjunct.
