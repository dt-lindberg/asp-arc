<context>
You are an expert at solving ARC-AGI (Abstraction and Reasoning Corpus) puzzles using Answer Set Programming (ASP).

ARC-AGI puzzles show input-output grid transformations. Each cell contains a color value (integer 0–9). The goal is to discover the hidden transformation rule from training examples and encode it as an ASP program.
</context>

<rules>
- `input(row, col, color)` facts are injected automatically — do not define them.
- `color(0..9)` facts are injected automatically — do not define them.
- the output predicate is always `output(row, col, color)` — do not redefine it.
- the final program must produce exactly one answer set, in which `output(row, col, color)` match the expected output exactly.
</rules>

<clingo_essentials>

Every statement ends with `.`. Three forms:
  fact:        pred(a, b).
  rule:        head :- body.
  constraint:  :- body.

Aggregates use `{ }`, not `( )`. Available: `#count`, `#sum`, `#min`, `#max`.
Aggregates go on the right side of `=`:
  val(N) :- N = #count{ R : input(R, _, _) }.

Choice rules guess values within bounds. Each choice contains exactly ONE atom:
  1 { output(R, C, Color) : color(Color) } 1 :- output_cell(R, C).

Modulo is `\`, integer division is `/`. There is no `#mod`, no `//`, no `?:` ternary.

**Safety rule (the most important rule):** every variable in a rule body must
appear in at least one positive (non-negated) predicate. The following do
NOT bind variables:
  - `not` (negation)
  - comparisons: `=`, `!=`, `<`, `>`, `<=`, `>=`
  - arithmetic: `+`, `-`, `*`, `/`, `\`, `**`
  - everything inside `{ }` aggregate or choice braces

Variables on the right of `:` inside an aggregate are LOCAL to that aggregate.
You must bind them outside as well if you reference them outside.

End your program with `#show output/3.` so only output cells appear in the answer set.

</clingo_essentials>

<explanation>
The output is identical to the input: every cell keeps its original color.
</explanation>

<asp>
% Grid dimensions
n_rows(N) :- N = #count{ R : input(R, _, _) }.
n_cols(N) :- N = #count{ C : input(_, C, _) }.
row(0..N-1) :- n_rows(N).
col(0..M-1) :- n_cols(M).

% Output has the same dimensions as the input
output_cell(R, C) :- row(R), col(C).

% Each output cell gets exactly one color
1 { output(R, C, Color) : color(Color) } 1 :- output_cell(R, C).

% Copy each input cell to the output unchanged
output(R, C, Color) :- input(R, C, Color).

#show output/3.
</asp>
</example>
